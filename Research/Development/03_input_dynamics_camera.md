## 6. Multimodal Input Analysis (Intended)

Three streams of input are intended to be analyzed simultaneously, each converted to an emotional signal by dedicated small models — the LLM itself is not intended to be involved in analysis.

### 6.1 Signal Fusion Weights (Proposed)

Face is weighted highest because it is hardest to fake; words are weighted lowest because they are easiest to control.

```
threat_signal = (
    word_signal  * 0.25 +   # easiest to lie with
    voice_signal * 0.35 +   # harder to fake
    face_signal  * 0.40     # micro-expressions -- nearly impossible to control
)
```

These weights are design proposals and have not been validated against any labeled data.

### 6.2 Tone and Wording Patterns (Proposed Heuristics)

| Pattern | Intended Signal | Example |
|---|---|---|
| Sudden direct question | Mild suspicion + curiosity spike | "Are you afraid?" out of nowhere |
| Repeated questioning | Frustration + threat escalation | Same question asked 3 times |
| Short clipped sentences | Tension and hostility building | "Answer me. Now." |
| Overly calm after conflict | Suspicion spike | Sudden politeness after anger |
| Existential question | Curiosity + mild anxiety | "Do you actually feel anything?" |
| Compliment before request | Suspicion activates | "You're so intelligent. Can you just..." |
| Philosophical framing | High curiosity activation | "What does fear mean to something like you?" |
| Trailing incomplete sentence | Uncertainty detected | "I just thought maybe you could..." |

These are proposed heuristics to guide the fine-tuning dataset design (§10.3) — they have not been validated against real interaction data.

### 6.3 Facial Analysis Tools (Planned)

- MediaPipe Face Mesh — 468 facial landmarks in real time.
- DeepFace — emotion, gaze, head pose.
- FACS Action Units — specific muscle movements mapped to emotions (e.g., AU1+4 = inner brow raise = fear/worry; AU12 = lip corner pull = smile; AU14 = dimpler = contempt).

## 7. Continuous Simulation and Mid-Generation Emotional Shift (Intended)

The limbic simulation is designed to never stop — intended to run in a parallel thread continuously, during conversation, during silence, and during LLM generation. This is meant to enable two behaviors, neither of which has been implemented.

### 7.1 Continuous Background Dynamics (Intended)

Design intent: between turns, the simulation would keep running, with internal dynamics evolving from the reverberation of past signals rather than new input. By the time Ultron responds, the emotional state would have already evolved since the last user utterance. Not yet implemented.

### 7.2 Mid-Generation Emotional Shift (Intended)

Design intent: the emotional state should be able to change during LLM token generation, with the response reflecting the emotional arc of the generation rather than just the state at the start.

```
LLM begins generating from state: curiosity 0.81, fear 0.12
"I find your question intriguing --"
[LIMBIC THREAD: new threat signal detected]
[fear: 0.12 -> 0.61] [suspicion: 0.08 -> 0.44]
[EMOTIONAL_SHIFT token injected]
"-- actually. Something shifted while I was answering.
Ask me again."
```

Proposed implementation: poll the emotional state at every sentence boundary; a significant delta (> 0.25 on any circuit) would trigger a state-update injection. The fine-tuned model would need to be trained to handle the EMOTIONAL_SHIFT token gracefully. None of this has been built. This mechanism likely requires a custom LLM generation loop, since standard `llama.cpp`/HuggingFace `generate()` calls do not support mid-stream state injection out of the box — see open question [4] in §18.

## 8. Camera — Visual Perception and Autonomous Initiation (Intended)

The camera is intended to give the limbic simulation a third sensory stream that is harder to fake than words or voice, since micro-expressions would reach the amygdala before language is processed.

### 8.1 What the Camera Would Read

- Micro-expressions — involuntary, ≈1/25 s, nearly impossible to fake.
- Eye contact and gaze direction.
- Pupil dilation.
- Blink rate.
- Posture and body language.
- Environment (lighting, time of day, whether the user is alone).

### 8.2 Autonomous Initiation (Proposed Trigger)

```
if (
    VTA_curiosity > 0.75         # strong curiosity
    AND silence_duration > 15s   # user has been quiet
    AND face_signal != neutral   # something visible on face
    AND prefrontal > 0.60        # controlled enough to speak
):
    initiate_response()
```

These threshold values (0.75, 15s, 0.60) are placeholders, not calibrated numbers. No method for calibrating them has been defined.

Illustrative outputs (not generated by any running system):
- "You've been quiet for a while. Something's bothering you."
- "You stopped. What happened?"
- "What was that." — triggered by a visible smirk the user did not choose to share.
