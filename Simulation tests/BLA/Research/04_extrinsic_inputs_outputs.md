# 04 — Extrinsic Inputs and Outputs

## Major afferents

| Source | Target preference | Functional role |
|--------|-------------------|-----------------|
| Sensory thalamus (e.g. medial geniculate) | LA | Fast, low-detail threat signals |
| Sensory / association cortex | LA, BA | High-detail, contextualized sensory information |
| Prefrontal cortex (prelimbic / infralimbic) | BA > LA | Top-down control, extinction vs expression |
| Hippocampus (ventral) | BA | Contextual gating, emotional memory |
| VTA dopamine neurons | PN and IN subtypes (projection-specific) | Salience, aversive prediction, extinction teaching signals |
| Locus coeruleus (noradrenaline) | Broad | Arousal, gain |
| Basal forebrain (acetylcholine) | PN + multiple IN classes | Attention, encoding precision |
| Raphe (serotonin) | PN, PV, NPY INs | Mood, impulse control |

Two parallel sensory routes are functionally important:
- **Fast thalamic** → rapid, relatively undifferentiated defensive bias.
- **Slow cortical** → object identity, social meaning, nuanced evaluation.

## Major efferents

| Target | Origin preference | Role |
|--------|-------------------|------|
| Central amygdala (CeA / CeL / CeM) | BLA PNs | Expression gateway for defensive / aggressive states |
| Nucleus accumbens (NAc) | Valence-specific ensembles | Approach / reward |
| Prefrontal cortex | BA | Reciprocal evaluation–control loop |
| Ventral hippocampus | BA | Context and memory |
| Bed nucleus of the stria terminalis (BNST) | BLA | Sustained anxiety-like states |
| Intercalated cells (ITCs) | BLA | Feed-forward inhibition onto CeA |

Projection-defined PN populations (NAc-projecting, CeA-projecting, vHPC-projecting) are intermingled yet form partially distinct local networks. CeA-projecting cells tend to suppress larger local ensembles.

## Implications for the PFE architecture

- BLA is the natural site for the “threat evaluation / emotional learning” node.
- Strong bidirectional links with PFC implement the evaluation-versus-control loop.
- Output to CeA is the primary path toward expression (and therefore the main target of prefrontal suppression).
- VTA dopamine onto BLA is a key candidate mechanism for post-stimulus excitability changes (emotional inertia support).
