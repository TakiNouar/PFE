# 04 — Extrinsic Inputs and Outputs

## Major afferents

| Source | Target preference | Functional role |
|--------|-------------------|-----------------|
| Sensory thalamus (e.g. medial geniculate) | LA | Fast threat signals (innate and learned) |
| Sensory / association cortex | LA, BA | High-detail, contextualized sensory information |
| Prefrontal cortex (prelimbic / infralimbic) | BA > LA | Top-down control, extinction vs expression |
| Hippocampus (ventral) | BA | Contextual gating, emotional memory |
| VTA dopamine neurons | PN and IN subtypes (projection-specific) | Salience, aversive prediction, extinction teaching |
| Locus coeruleus (noradrenaline) | Broad (+ astrocytes) | Arousal, gain |
| Basal forebrain (acetylcholine) | PN + multiple IN classes | Attention, encoding precision |
| Raphe (serotonin) | PN, PV, NPY INs | Mood, impulse control |

Two parallel sensory routes:

- **Fast thalamic** → rapid processing of **both innate** (e.g. visual looming) **and learned** (e.g. conditioned auditory) threats. Subcortical thalamic–BLA pathway as a shortcut for salient stimuli. Perturbing it impairs defensive switching for both types. **Mechanistic dissociation:** β-adrenergic receptors are required for innate-threat responses via this route but **not** for learned-threat responses (Khalil et al. 2023, *eLife*).
- **Slow cortical** → object identity, social meaning, nuanced evaluation.

## Major efferents

| Target | Origin preference | Role |
|--------|-------------------|------|
| Central amygdala (CeA / CeL / CeM) | BLA PNs | Expression gateway for defensive / aggressive states |
| Nucleus accumbens (NAc) | Valence-specific ensembles | Approach / reward |
| Prefrontal cortex | BA | Reciprocal evaluation–control loop |
| Ventral hippocampus | BA | Context and memory |
| Bed nucleus of the stria terminalis (BNST) | BLA | Sustained anxiety-like states |
| Intercalated cells (ITCs) | BLA | Feed-forward inhibition onto CeA |

**Projection-defined valence encoding:** NAc-, CeM-, and vHPC-projecting PN populations are intermingled spatially but functionally biased (Beyeler et al. 2018, *Cell Reports*):

- **NAc-projecting** → enriched for positive/appetitive valence.
- **CeM-projecting** → enriched for negative/aversive valence; tend to suppress larger local ensembles via feedforward inhibition.
- **vHPC-projecting** → contextual and mixed valence.

Projection identity correlates with but is not identical to valence — neurons can project to multiple targets and respond to both valences. Anatomical arrangement (intermingled vs partially segregated) remains debated.

## Implications for the PFE architecture

- BLA is the natural site for threat evaluation / emotional learning.
- Strong bidirectional links with PFC implement evaluation-versus-control.
- Output to CeA is the primary path toward expression (and the main target of prefrontal suppression).
- VTA dopamine onto BLA is a candidate for post-stimulus excitability (emotional inertia support).

**Experience-dependent routing bias:** prior positive (enrichment) or negative (chronic stress) experience differentially changes responsiveness of projection-specific BLA PNs (e.g. NAc-core vs BNST). Chemogenetic mimicry confirms causality. Same external input is routed differently depending on prior state — biological basis for history-dependent emotional response (sensitization analog). (Antonoudiou et al. 2024, *Cell Reports*.)
